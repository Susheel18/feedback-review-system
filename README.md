# Smart Student Feedback & Review Management System

A backend Feedback & Review Management System built using Java, Spring Boot, MySQL, and REST APIs.

## Features

- User Management
- Feedback Management
- REST APIs
- MySQL Database Integration
- Spring Boot Backend
- CRUD Operations

## Tech Stack

- Java 21
- Spring Boot
- MySQL
- Spring Data JPA
- Maven

## APIs Implemented

### User APIs
- Save User
- Get All Users
- Get User By ID
- Delete User

### Feedback APIs
- Save Feedback
- Get All Feedbacks
- Get Feedback By ID
- Delete Feedback
